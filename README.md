## 🚀 Getting Started

Choose a platform you're interested in and visit the corresponding repository for platform-specific setup instructions.

### General Setup Steps:

1. Clone the desired repository
   ```bash
   git clone https://github.com/mahimairaja/demo-[platform]-chatbot
   ```

2. Install dependencies
   ```bash
   cd demo-[platform]-chatbot
   npm install  # or other package manager command
   ```

3. Configure your environment variables
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and configuration
   ```

4. Run the chatbot
   ```bash
   npm start  # or appropriate start command
   ```
